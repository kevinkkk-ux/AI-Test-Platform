## Ch04 数据分析、可视化与报告生成

前两章我们学习了项目的基础架构和核心工作流编排。我们已经知道，系统能够理解用户的自然语言，生成SQL语句，并从数据库中获取数据。但获取到原始数据之后呢？原始数据往往是枯燥的数字和文本，我们需要对它进行分析、可视化，并最终整合成一份易于理解的分析报告。

接下来，我们就来学习完成这三个任务的模块：

- `data_analyzer.py`：数据分析器，负责对原始数据进行统计分析并生成洞察。
- `visualizer.py`：数据可视化模块，负责将分析结果绘制成图表。
- `report_generator.py`：报告生成器，负责将分析结果、图表和AI总结整合成一份完整的报告。

这三个模块共同构成了智能体的“表达与呈现”能力。

2. **核心入口：analyze_data() 方法**

   ```python
       def analyze_data(self, data: List[Dict[str, Any]], query: str, sql: str) -> Dict[str, Any]:
           """分析数据并生成分析结果"""
   
           if not data:
               return {
                   "summary": "查询结果为空",
                   "insights": [],
                   "statistics": {}
               }
   
           df = pd.DataFrame(data)
   
           # 基本统计分析
           statistics = self._calculate_statistics(df)
   
           # 生成分析洞察
           insights = self._generate_insights(df, query)
   
           # 生成数据摘要
           summary = self._generate_summary(df, query, sql)
   
           return {
               "summary": summary,
               "insights": insights,
               "statistics": statistics,
               "dataframe": df
           }
   ```

   - 这个方法接收三个参数：`data`（原始数据，类型为列表的字典）、`query`（用户原始查询）、`sql`（生成的SQL语句）。
   - 首先，它将原始数据 `data` 转换为一个 `pandas` 的 `DataFrame` 对象。`pandas` 是Python中非常强大的数据分析库，提供了丰富的统计分析功能。
   - 然后，它调用三个内部方法，分别完成**统计计算**、**洞察生成**和**摘要生成**。
   - 最终，它返回一个包含 summary、insights、statistics 和 dataframe 的字典，这些结果将被后续模块使用。

3. **统计计算：_calculate_statistics() 方法**

   ```python
       def _calculate_statistics(self, df: pd.DataFrame) -> Dict[str, Any]:
           """计算统计信息"""
           statistics = {
               "row_count": len(df),
               "column_count": len(df.columns),
               "columns": list(df.columns),
               "dtypes": {col: str(dtype) for col, dtype in df.dtypes.items()}
           }
   
           # 数值型列的统计
           numeric_cols = df.select_dtypes(include=[np.number]).columns
           if len(numeric_cols) > 0:
               statistics["numeric_stats"] = {
                   col: {
                       "mean": float(df[col].mean()) if not pd.isna(df[col].mean()) else None,
                       "median": float(df[col].median()) if not pd.isna(df[col].median()) else None,
                       "min": float(df[col].min()) if not pd.isna(df[col].min()) else None,
                       "max": float(df[col].max()) if not pd.isna(df[col].max()) else None,
                       "std": float(df[col].std()) if not pd.isna(df[col].std()) else None,
                       "sum": float(df[col].sum()) if not pd.isna(df[col].sum()) else None
                   }
                   for col in numeric_cols[:5]  # 限制显示列数
               }
   
           # 类别型列的统计
           categorical_cols = df.select_dtypes(include=['object']).columns
           if len(categorical_cols) > 0:
               statistics["categorical_stats"] = {
                   col: {
                       "unique_count": df[col].nunique(),
                       "top_values": df[col].value_counts().head(5).to_dict()
                   }
                   for col in categorical_cols[:3]
               }
   
           return statistics
   ```

   - **基本统计信息**：首先记录行数、列数、列名和数据类型。
   - 数值型列统计：使用 df.select_dtypes(include=[np.number]) 筛选出所有数值型列，然后对每一列计算平均值、中位数、最小值、最大值、标准差和总和。注意，这里限制了 [:5]，只显示前5个数值列，避免信息过载。
   - 类别型列统计：使用 df.select_dtypes(include=['object']) 筛选出所有类别型（字符串）列，然后统计唯一值的数量和出现频率最高的前5个值。同样，这里限制了 [:3]。
   - **为什么使用 pandas？** `pandas` 提供了大量高效的数据分析函数，让我们可以用几行代码完成复杂的统计计算，极大地提高了开发效率。

4. **洞察生成：_generate_insights() 和 _generate_llm_insights() 方法**

   ```python
       def _generate_insights(self, df: pd.DataFrame, query: str) -> List[str]:
           """生成数据洞察"""
           insights = []
   
           # 基本洞察
           insights.append(f"查询结果包含 {len(df)} 条记录和 {len(df.columns)} 个字段")
   
           # 数值洞察
           numeric_cols = df.select_dtypes(include=[np.number]).columns
           for col in numeric_cols[:3]:
               if not df[col].isna().all():
                   insights.append(f"字段 '{col}': 平均值={df[col].mean():.2f}, "
                                   f"最大值={df[col].max():.2f}, 最小值={df[col].min():.2f}")
   
           # 使用LLM生成更深入的洞察
           try:
               llm_insights = self._generate_llm_insights(df, query)
               insights.extend(llm_insights)
           except Exception as e:
               logger.warning(f"LLM洞察生成失败: {str(e)}")
   
           return insights[:5]  # 最多返回5条洞察
   ```

   - _generate_insights 方法首先通过简单的统计计算生成一些基本洞察（如记录数、平均值等）。
   - 然后，它调用 _generate_llm_insights 方法，利用大模型生成更深入、更智能的洞察。

   ```python
       def _generate_llm_insights(self, df: pd.DataFrame, query: str) -> List[str]:
           """使用LLM生成洞察"""
           # 准备数据摘要
           data_summary = df.describe().to_string()
           head_data = df.head(10).to_string()
   
           prompt = f"""基于以下数据分析结果，生成3-5条关键洞察（每条不超过50字）：
   
                   用户查询：{query}
   
                   数据摘要（统计信息）：
                   {data_summary}
   
                   前10条数据示例：
                   {head_data}
   
                   请返回格式化的洞察列表，每条一行。"""
   
           response = self.client.chat.completions.create(
               model=self.config["model"],
               messages=[
                   {"role": "system", "content": "你是一个数据分析专家，请提供简洁的数据洞察。"},
                   {"role": "user", "content": prompt}
               ],
               temperature=0.3,
               max_tokens=500
           )
   
           insights_text = response.choices[0].message.content.strip()
           insights = [insight.strip() for insight in insights_text.split('\n') if insight.strip()]
           return insights
   ```

   - **提示词工程**：这里再次运用了提示词工程技术。`prompt` 包含了 `df.describe().to_string()`（数据的统计摘要）和 `df.head(10).to_string()`（前10条数据示例），为大模型提供了丰富的上下文信息。
   - 大模型根据这些信息，生成3-5条简洁的关键洞察，每条不超过50字。
   - **传统统计 + AI洞察**：这种方法将传统的统计分析（如计算平均值）与AI的智能分析能力结合起来，既保证了基础信息的准确性，又提供了更深层次的见解。

5. **摘要生成：_generate_summary() 方法**

   ```python
       def _generate_summary(self, df: pd.DataFrame, query: str, sql: str) -> str:
           """生成数据摘要"""
           summary = f"## 数据分析报告\n\n"
           summary += f"**查询时间**: {datetime.now().strftime('%Y-%m-%d %H:%M:%S')}\n\n"
           summary += f"**用户查询**: {query}\n\n"
           summary += f"**生成的SQL**: ```sql\n{sql}\n```\n\n"
           summary += f"**数据概览**: 共查询到 {len(df)} 条记录，包含 {len(df.columns)} 个字段\n\n"
   
           # 数据类型
           summary += "### 字段信息\n\n"
           for col in df.columns:
               dtype = str(df[col].dtype)
               summary += f"- **{col}**: {dtype}\n"
   
           return summary
   ```

   - 这个方法生成一段 Markdown 格式的文本摘要，包含查询时间、用户查询、生成的SQL语句、数据概览和字段信息。
   - 这段摘要将作为最终报告的一部分，让用户了解分析的基本信息。

**小结**：`data_analyzer.py` 模块通过 `pandas` 进行传统统计分析，并利用大模型生成智能洞察，将原始数据转化为结构化的、富含信息的分析结果。

2. **核心功能：create_visualization() 方法**

   ```python
       def create_visualization(self,
                                data: List[Dict[str, Any]],
                                chart_type: str,
                                x_column: Optional[str] = None,
                                y_column: Optional[str] = None,
                                title: Optional[str] = None) -> Optional[str]:
           """创建可视化图表 - 返回base64编码的图片HTML"""
   
           if not data:
               logger.warning("没有数据可供可视化")
               return "<p style='color:#999;text-align:center;'>暂无数据可生成图表</p>"
   
           try:
               import matplotlib
               matplotlib.use('Agg')
               import matplotlib.pyplot as plt
   
               df = pd.DataFrame(data)
   
               # 自动选择字段
               if not x_column:
                   x_column = self._auto_select_x_column(df)
               if not y_column:
                   y_column = self._auto_select_y_column(df)
   
               if not x_column or not y_column:
                   logger.warning("无法自动选择字段进行可视化")
                   return "<p style='color:#999;text-align:center;'>无法自动选择图表字段</p>"
   
               # 创建图表
               plt.figure(figsize=(10, 6))
   
               if chart_type == "饼图":
                   self._create_pie_chart(df, x_column, y_column)
               elif chart_type == "柱状图":
                   self._create_bar_chart(df, x_column, y_column)
               elif chart_type == "折线图":
                   self._create_line_chart(df, x_column, y_column)
               elif chart_type == "散点图":
                   self._create_scatter_chart(df, x_column, y_column)
               else:
                   self._create_bar_chart(df, x_column, y_column)
   
               # 设置标题
               if title:
                   plt.title(title)
               else:
                   plt.title(f"{y_column} by {x_column}")
   
               plt.tight_layout()
   
               # 保存为base64图片
               buf = io.BytesIO()
               plt.savefig(buf, format='png', dpi=100, bbox_inches='tight')
               buf.seek(0)
               img_base64 = base64.b64encode(buf.getvalue()).decode('utf-8')
               plt.close()
   
               # 返回HTML图片
               return f'<img src="data:image/png;base64,{img_base64}" style="width:100%;max-width:800px;height:auto;display:block;margin:0 auto;">'
   
           except Exception as e:
               logger.error(f"图表生成失败: {str(e)}")
               return f"<p style='color:red;text-align:center;'>图表生成失败: {str(e)}</p>"
   
       def _auto_select_x_column(self, df: pd.DataFrame) -> Optional[str]:
           """自动选择X轴字段"""
           # 优先选择类别型字段
           for col in df.columns:
               if df[col].dtype == 'object':
                   return col
           # 选择第一个非数值型字段
           for col in df.columns:
               if df[col].dtype != 'object':
                   return col
           return df.columns[0] if len(df.columns) > 0 else None
   
       def _auto_select_y_column(self, df: pd.DataFrame) -> Optional[str]:
           """自动选择Y轴字段"""
           # 优先选择数值型字段
           for col in df.columns:
               if df[col].dtype in ['int64', 'float64']:
                   return col
           # 如果没有数值型字段，选择第二个字段
           return df.columns[1] if len(df.columns) > 1 else df.columns
   
       def _create_pie_chart(self, df: pd.DataFrame, x_col: str, y_col: str):
           """创建饼图"""
           import matplotlib.pyplot as plt
   
           # 只取前10个数据，避免饼图太拥挤
           if len(df) > 10:
               df = df.head(10)
   
           values = df[y_col].tolist()
           labels = df[x_col].tolist()
   
           # 过滤掉0值
           filtered_data = [(v, l) for v, l in zip(values, labels) if v > 0]
           if not filtered_data:
               # 如果所有值都是0，使用所有数据
               filtered_data = list(zip(values, labels))
   
           values = [v for v, _ in filtered_data]
           labels = [l for _, l in filtered_data]
   
           plt.pie(values, labels=labels, autopct='%1.1f%%', startangle=90)
           plt.axis('equal')
   
       def _create_bar_chart(self, df: pd.DataFrame, x_col: str, y_col: str):
           """创建柱状图"""
           import matplotlib.pyplot as plt
   
           # 只取前20个数据
           if len(df) > 20:
               df = df.head(20)
   
           x = range(len(df))
           plt.bar(x, df[y_col].tolist())
           plt.xticks(x, df[x_col].tolist(), rotation=45, ha='right')
           plt.xlabel(x_col)
           plt.ylabel(y_col)
   
       def _create_line_chart(self, df: pd.DataFrame, x_col: str, y_col: str):
           """创建折线图"""
           import matplotlib.pyplot as plt
   
           # 只取前50个数据
           if len(df) > 50:
               df = df.head(50)
   
           x = range(len(df))
           plt.plot(x, df[y_col].tolist(), marker='o', linestyle='-', linewidth=2, markersize=6)
           plt.xticks(x, df[x_col].tolist(), rotation=45, ha='right')
           plt.xlabel(x_col)
           plt.ylabel(y_col)
           plt.grid(True, alpha=0.3)
   
       def _create_scatter_chart(self, df: pd.DataFrame, x_col: str, y_col: str):
           """创建散点图"""
           import matplotlib.pyplot as plt
   
           # 只取前100个数据
           if len(df) > 100:
               df = df.head(100)
   
           plt.scatter(df[x_col].tolist(), df[y_col].tolist(), alpha=0.6, s=50)
           plt.xlabel(x_col)
           plt.ylabel(y_col)
           plt.grid(True, alpha=0.3)
   
   
   # 全局可视化器实例
   visualizer = DataVisualizer()
   ```

   - 这个方法接收原始数据、图表类型、X轴字段、Y轴字段和标题，生成一个 base64 编码的图片HTML字符串。
   - **数据准备**：同样将原始数据转换为 `DataFrame`。
   - **字段自动选择**：如果用户没有指定 X 轴和 Y 轴字段，系统会尝试自动选择。这是通过分析 DataFrame 的数据类型来实现的。
   - **图表类型判断**：根据 `chart_type` 参数（如"柱状图"、"折线图"、"饼图"、"散点图"、"热力图"），使用 `matplotlib` 和 `pyecharts` 等库生成相应的图表。
   - **base64编码**：生成的图表会被转换为 base64 编码的字符串，嵌入到 HTML 的 `<img>` 标签中，方便在网页中直接显示。

**小结**：`visualizer.py` 模块将分析结果转化为直观的图表，使数据更容易被理解。它支持多种图表类型，并具备自动字段选择功能，提高了用户体验。

1. **核心入口：generate_report() 方法**

   ```python
       def generate_report(self,
                           analysis_result: Dict[str, Any],
                           query: str,
                           sql: str,
                           chart_html: Optional[str] = None) -> str:
           """生成完整的数据分析报告"""
   
           report_parts = []
   
           # 1. 报告标题
           report_parts.append(f"# AI数据分析报告\n\n")
           report_parts.append(f"**生成时间**: {datetime.now().strftime('%Y-%m-%d %H:%M:%S')}\n\n")
           report_parts.append(f"---\n\n")
   
           # 2. 查询信息
           report_parts.append("## 查询信息\n\n")
           report_parts.append(f"**用户查询**: {query}\n\n")
           report_parts.append(f"**生成的SQL**: \n```sql\n{sql}\n```\n\n")
   
           # 3. 数据摘要
           report_parts.append("## 数据摘要\n\n")
           report_parts.append(analysis_result.get("summary", "无摘要信息") + "\n\n")
   
           # 4. 数据洞察
           insights = analysis_result.get("insights", [])
           if insights:
               report_parts.append("## 关键洞察\n\n")
               for i, insight in enumerate(insights, 1):
                   report_parts.append(f"{i}. {insight}\n\n")
   
           # 5. 统计信息
           statistics = analysis_result.get("statistics", {})
           if statistics:
               report_parts.append("## 统计分析\n\n")
               report_parts.append(f"- 记录数: {statistics.get('row_count', 0)}\n")
               report_parts.append(f"- 字段数: {statistics.get('column_count', 0)}\n")
   
               numeric_stats = statistics.get("numeric_stats", {})
               if numeric_stats:
                   report_parts.append("\n### 数值统计\n\n")
                   report_parts.append("| 字段 | 平均值 | 中位数 | 最小值 | 最大值 | 总和 |\n")
                   report_parts.append("|------|--------|--------|--------|--------|------|\n")
                   for col, stats in numeric_stats.items():
                       report_parts.append(
                           f"| {col} | {stats.get('mean', 'N/A'):.2f} | "
                           f"{stats.get('median', 'N/A'):.2f} | "
                           f"{stats.get('min', 'N/A'):.2f} | "
                           f"{stats.get('max', 'N/A'):.2f} | "
                           f"{stats.get('sum', 'N/A'):.2f} |\n"
                       )
   
           # 6. 可视化图表
           if chart_html:
               report_parts.append("\n\n## 数据可视化\n\n")
               report_parts.append(chart_html + "\n\n")
   
           # 7. 使用LLM生成总结
           report_parts.append("\n\n## AI分析总结\n\n")
           llm_summary = self._generate_llm_summary(analysis_result, query)
           report_parts.append(llm_summary + "\n\n")
   
           # 8. 建议
           report_parts.append("\n\n## 建议\n\n")
           suggestions = self._generate_suggestions(analysis_result, query)
           for suggestion in suggestions:
               report_parts.append(f"- {suggestion}\n")
   
           return "\n".join(report_parts)
   ```

   - 这个方法接收 analysis_result（来自 DataAnalyzer 的分析结果）、query（用户查询）、sql（生成的SQL）和可选的 chart_html（可视化图表HTML），生成一份完整的 Markdown 格式报告。
   - 报告结构：报告被清晰地组织为8个部分： 
     1. **报告标题**：包含标题和生成时间。
     2. **查询信息：**展示用户原始查询和生成的SQL语句。
     3. **数据摘要**：来自 `DataAnalyzer` 的摘要信息。
     4. **关键洞察**：来自 `DataAnalyzer` 的洞察列表。
     5. **统计分析**：以表格形式展示数值统计信息。
     6. **数据可视化**：嵌入图表HTML。
     7. **AI分析总结：**使用大模型生成的总结性文字。
     8. **建议：**基于分析结果生成的建议。

2. **AI总结生成：_generate_llm_summary() 方法**

   ```python
       def _generate_llm_summary(self, analysis_result: Dict[str, Any], query: str) -> str:
           """使用LLM生成总结"""
           try:
               prompt = f"""基于以下数据分析结果，生成一段简洁的总结报告（100-200字）：
   
               用户查询：{query}
   
               数据洞察：
               {chr(10).join(analysis_result.get('insights', ['无洞察']))}
   
               统计信息：
               总记录数：{analysis_result.get('statistics', {}).get('row_count', 0)}
               字段数：{analysis_result.get('statistics', {}).get('column_count', 0)}"""
   
               response = self.client.chat.completions.create(
                   model=self.config["model"],
                   messages=[
                       {"role": "system", "content": "你是一个数据分析报告撰写专家，请生成简洁专业的分析总结。"},
                       {"role": "user", "content": prompt}
                   ],
                   temperature=0.3,
                   max_tokens=500
               )
   
               return response.choices[0].message.content.strip()
           except Exception as e:
               logger.error(f"LLM总结生成失败: {str(e)}")
               return "无法生成AI分析总结。"
   ```

   - 这个方法再次利用大模型，基于洞察和统计信息，生成一段100-200字的总结性文字，为报告增加专业性和可读性。

3. **建议生成：_generate_suggestions() 方法**

   ```python
       def _generate_suggestions(self, analysis_result: Dict[str, Any], query: str) -> List[str]:
           """生成建议"""
           suggestions = []
   
           # 基于分析结果生成建议
           statistics = analysis_result.get("statistics", {})
           row_count = statistics.get("row_count", 0)
   
           if row_count == 0:
               suggestions.append("查询结果为空，建议检查查询条件或数据是否完整")
           elif row_count < 10:
               suggestions.append("数据量较少，建议扩大查询范围以获得更准确的分析")
           else:
               suggestions.append("可以进一步分析数据的时间趋势或分类特征")
   
           suggestions.append("考虑使用不同的图表类型来展示数据的不同维度")
           suggestions.append("建议定期更新数据以确保分析的时效性")
   
           return suggestions[:3]
   ```

   - 这个方法基于统计信息，生成一些实用的建议。例如，如果数据量较少，建议扩大查询范围；如果数据量充足，建议进一步分析时间趋势等。
